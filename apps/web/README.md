# VeSCA Market Web

This is the Next.js frontend for VeSCA Market, a Sui dApp for trading vested token positions.

## Getting Started

### DEMO

The project is currently deployed at sui's test network.

Try our [**DEMO**](https://vesca-market.vercel.app/)

### Check contracts

The Move packages are part of this monorepo:

- `../../contracts/vesca_market`
- `../../contracts/test_vesca`

Deployment addresses are documented in `../../docs/addresses.md`.

## Get test tokens

To actually operate in the app, you'll need some test tokens.
